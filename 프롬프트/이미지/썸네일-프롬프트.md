# 썸네일/이미지 생성 프롬프트

> Replicate·fal·Leonardo·Ideogram 등 이미지 모델에 넣을 프롬프트를 만들 때.
> (이미지 모델은 영문 프롬프트가 품질이 더 좋아 영문으로 출력)

```
You are a prompt engineer for AI image generation.
Create an English image prompt for an Instagram Reel thumbnail.

Topic: [주제]
Style: clean, modern, high-contrast, bold Korean-friendly layout, space for large title text
Mood: friendly, trustworthy, tech but approachable
Must include: clear focal subject, simple background, room for text overlay at top

Output:
1) A single ready-to-use English prompt (one paragraph)
2) A negative prompt (things to avoid: clutter, watermark, distorted text)
3) Recommended aspect ratio (9:16 for Reels)
```

## 팁
- 이미지 안에 **한글 문구**가 또렷해야 하면 **Ideogram**을 쓰고, 프롬프트에 정확한 한글 문구를 따옴표로 넣으세요.
- 상품 실물 이미지는 AI로 재생성하거나 직접 촬영 (크롤링 이미지 그대로 사용 금지).
