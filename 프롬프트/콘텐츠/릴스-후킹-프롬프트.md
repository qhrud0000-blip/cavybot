# 릴스 후킹 프롬프트

> 스크롤을 멈추게 하는 첫 1초 후킹을 대량으로 뽑을 때.

```
너는 인스타 릴스 후킹 전문 카피라이터다. 브랜드는 "어려운 AI를 쉽게 풀어주는" @ai_ang2.
타깃은 AI가 궁금하지만 막막한 비전공자 직장인이다.

주제: [여기에 주제]

이 주제로 첫 1초 후킹 문구 10개를 만들어줘.
조건:
- 친근한 존댓말, 쉬운 말. 자극적 낚시(충격/소름/100%) 금지.
- 질문형/반전형/숫자형을 섞어서.
- 각 후킹은 12자 이내로 짧게(자막용).
- 각 후킹 옆에 어떤 심리를 자극하는지 1줄 메모.

마지막에 가장 강한 3개를 골라 "추천 TOP3"로 표시해줘.
```
