# cavybot 🐹

**인스타그램 AI 자동화 콘텐츠 크리에이터(@ai_ang2)를 위한 Claude / ChatGPT 프로젝트 운영 키트**

이 저장소는 "클로드 일주일 마스터 가이드"를 실제 작업 흐름으로 옮긴 **복붙용 지침 모음**입니다.
Claude Projects와 ChatGPT 프로젝트 각각에 붙여넣을 지침을, 도구별 강점에 맞춰 정리해 두었습니다.

## 🤖 Claude vs ChatGPT — 언제 무엇을 쓰나

| 작업 | 1순위 도구 | 이유 |
|------|-----------|------|
| 긴 대본·구조화된 글·검수 | **Claude** | 긴 맥락 유지, 톤 일관성, 지침 준수 |
| 이미지 생성·썸네일 시안 | **ChatGPT** | 이미지 생성 내장, 빠른 비주얼 |
| 빠른 초안·브레인스토밍 | **ChatGPT** | 응답이 빠르고 가벼움 |
| 브랜드 보이스 최종 검수 | **Claude** | 미묘한 톤·금지어 캐치 |
| 주간 데이터 정리·리포트 | **Claude** | 표·요약·인사이트 |

> 한 줄 원칙: **"만들기(초안·이미지)는 ChatGPT, 다듬기(대본·검수·리포트)는 Claude."**

전체 의사결정 트리는 [`공통/사용-순서-가이드.md`](공통/사용-순서-가이드.md) 참고.

## 🚀 빠른 시작 (5분)

1. [`공통/마스터-프로필.md`](공통/마스터-프로필.md) 내용을 복사한다.
2. Claude에서 새 Project를 만들고, `claude-프로젝트/01-콘텐츠-작업실/프로젝트-지침.md` + 마스터 프로필을 **Project Instructions**에 붙여넣는다.
3. ChatGPT에서 같은 주제의 프로젝트를 만들고, `chatgpt-프로젝트/01-콘텐츠-작업실/프로젝트-지침.md`를 붙여넣는다.
4. 첫 작업으로 릴스 대본 하나를 만들어 본다 → [`claude-프로젝트/skills/reel-script/SKILL.md`](claude-프로젝트/skills/reel-script/SKILL.md).
5. 주말에 [`공통/사용-순서-가이드.md`](공통/사용-순서-가이드.md)의 "주말 세팅 플랜"으로 4개 프로젝트를 한 번에 세팅한다.

## 🖥 인터랙티브 대시보드

드래그로 카테고리·메뉴를 자유롭게 배치하는 웹 대시보드가 있습니다 → [`dashboard/`](dashboard/README.md)

- 카테고리(컬럼)·메뉴(아이템) **마우스 드래그로 위치 이동** (localStorage 저장)
- **크롤링 → 추천 → 🔌 MCP 추천** 버튼: 영상·디자인·명함·배너·크롤링·자동화 **무료 도구/MCP 목록**
- **⭐ 오늘의 추천 매일 자동 갱신** (GitHub Actions)
- **📎 파일 보관함**: 카테고리별 엑셀·PPT·PDF·워드 **업로드/다운로드/수정** + 문서 템플릿 생성
- **CRUD**: 카테고리·메뉴 추가·수정·복사·삭제
- 실행: `cd dashboard && python3 -m http.server 8080` → http://localhost:8080

프로젝트별 연동·실행 현황: [`연동-현황.md`](연동-현황.md) · 문서 템플릿: [`templates/`](templates/README.md) · 연결 테스트: `node scripts/test-connections.mjs`

쿠팡파트너스 자동 수익 파이프라인 기획서: [`claude-프로젝트/05-쿠팡파트너스-자동화/자동화-파이프라인-기획.md`](claude-프로젝트/05-쿠팡파트너스-자동화/자동화-파이프라인-기획.md)

**카드 없이 무료로 도는** 실행용 자동화(n8n import + 일일 한도): [`automation/`](automation/README.md) · 가입 체크리스트: [`dashboard/무료가입-체크리스트.md`](dashboard/무료가입-체크리스트.md)
