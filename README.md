# cavybot — Claude & ChatGPT 프로젝트 지침 모음

마케팅·디자인 대행 + 콘텐츠·강의 + 개인 법률 건을 운영하는 분을 위한 **AI 프로젝트 지침 세트**입니다.
실제 운영 중인 프로젝트 목록(스크린샷 기준 13개)에 1:1로 맞춰 기획했습니다.
목표: 매번 설명을 반복하지 않고, 각 프로젝트가 **그 주제의 전문가처럼** 바로 일하도록 만드는 것.

## 폴더 구조
```
cavybot/
├── README.md                 ← 전체 인덱스(이 문서)
├── 공통/
│   ├── 마스터-프로필.md        ← 모든 대화 공통 전역 지침
│   └── 사용-순서-가이드.md      ← 도구/모델/연동 선택법
├── claude-프로젝트/           ← Claude Projects 13종 (+ README 매핑표)
│   └── 01~13/지침.md
└── chatgpt-프로젝트/          ← ChatGPT Projects 13종 (+ README 매핑표)
    └── 01~13/지침.md
```

## 쓰는 법 (3단계)
1. `공통/마스터-프로필.md` → Claude Settings·ChatGPT 맞춤설정에 붙여넣기
2. 각 `01~13/지침.md`의 **코드블록**을 복사 → 해당 프로젝트의 "지침/Instructions"에 붙여넣기
3. 각 지침 하단 "업로드 추천"의 파일을 프로젝트에 올리기
