# cavybot — Claude & ChatGPT 프로젝트 지침 모음

인스타그램 AI 자동화 콘텐츠 채널 **@ai_ang2** 운영을 위한 **Claude / ChatGPT 프로젝트 세팅 지침서**입니다.
노션 가이드 〈클로드 일주일 안에 마스터하는 방법〉을 기반으로, 크리에이터 1인 운영 상황에 맞춰
"매번 처음부터 설명하는 자판기 워크플로우"를 끝내고 **AI가 나를 기억하는 작업 환경**을 만드는 것이 목표입니다.

## 어떻게 쓰나요 (3단계)

1. **공통/마스터-프로필.md** 내용을 복사 → Claude `Settings → Profile`, ChatGPT `설정 → 맞춤설정`에 붙여넣기
2. 각 프로젝트 폴더의 **`프로젝트-지침.md`** 내용을 복사 → 해당 플랫폼에서 같은 이름의 프로젝트를 만들고 "지침/Instructions" 칸에 붙여넣기
3. **claude-프로젝트/skills/** 의 `SKILL.md` 들은 Claude Code/Cowork 사용 시 `.claude/skills/<이름>/SKILL.md` 경로에 그대로 복사

> 📌 모든 지침서는 그대로 복붙해서 쓸 수 있도록 작성돼 있습니다. `[대괄호]` 부분만 본인 정보로 바꾸세요.

## Claude vs ChatGPT — 같은 4개 프로젝트를 둘 다 만드는 이유

| | Claude 프로젝트 | ChatGPT 프로젝트 |
|--|----------------|------------------|
| 강점 | 긴 글·전략·코드, Artifacts(라이브 결과물), 일관된 톤 | 빠른 응답, 이미지 생성(DALL·E), 광범위한 플러그인 |
| 본 세팅에서의 역할 | 깊이 있는 기획·대본·자동화 | 빠른 초안·아이디어 양산·이미지 |

두 도구의 지침 주제(4개 프로젝트)는 동일하게 맞췄고, 각 플랫폼 특성에 맞게 문구를 최적화했습니다.
한 쪽만 쓰셔도 되고, 작업 성격에 따라 번갈아 쓰셔도 됩니다.
