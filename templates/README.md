# 📁 템플릿

엑셀/문서 작업용 시작 템플릿입니다. CSV는 더블클릭하면 엑셀/구글시트에서 바로 열립니다.

| 파일 | 용도 |
|------|------|
| [콘텐츠-캘린더.csv](콘텐츠-캘린더.csv) | 주간 발행 계획 (요일×채널×주제×상태) |
| [주간리포트.csv](주간리포트.csv) | 성과 기록 (조회/저장/공유/도달) |

## 대시보드 파일 보관함과의 관계

- 이 폴더의 CSV는 **기본 제공 템플릿**(깃에 저장, 누구나 다운로드).
- 대시보드의 📎 **파일 보관함**은 카테고리별로 **엑셀·PPT·PDF·워드 파일을 직접 업로드/다운로드**(브라우저 IndexedDB 저장)하는 공간입니다.
  - 수정 흐름: 보관함에서 **다운로드 → 엑셀/워드/PPT로 편집 → 다시 업로드**.
  - 새 문서 만들기: 보관함의 `📊엑셀 📝워드 📄PDF 📑PPT 📋CSV` 버튼으로 즉시 생성·다운로드.
    (엑셀/PDF/PPT 생성은 라이브러리를 CDN에서 불러오므로 인터넷 필요. 엑셀 실패 시 CSV로 자동 대체)
