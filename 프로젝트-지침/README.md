## 플랫폼 선택 원칙

- **만들기(아이디어·이미지·영상·빠른 초안) → ChatGPT** (이미지/영상 생성 내장, Canva GPT)
- **다듬기(대본·검수·구조화·긴 문서·법률 정리) → Claude** (긴 맥락·일관성·정확성)
