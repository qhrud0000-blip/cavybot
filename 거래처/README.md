# 🤝 거래처 관리

거래처(협업 브랜드, 광고주, 공급처) 정보를 정리하는 공간입니다.

## 거래처 파일

- 대시보드 `🤝 거래처` 카드의 헤더 **📎 버튼 → 파일 보관함**에서
  계약서·견적서·정산표(엑셀/PDF/워드 등)를 **업로드/다운로드/수정**하세요.
- 파일은 이 기기 브라우저(IndexedDB)에 저장됩니다. 민감 문서는 별도 안전 저장소에도 백업하세요.

## 거래처 연락처 목록 (비밀 아님만)

연락처·담당자 등 **비밀이 아닌 정보**는 아래 표나 `거래처-목록.csv`로 관리해도 됩니다.
**로그인 계정·비밀번호 같은 자격증명은 여기 쓰지 말고 🔐 보안 금고**에 넣으세요.

| 거래처 | 담당자 | 연락처 | 분야 | 상태 | 메모 |
|--------|--------|--------|------|------|------|
| 예) ○○브랜드 | 김담당 | email | 광고 | 협의중 | |

## 거래처 자격증명

거래처 포털 로그인 등 **아이디/비밀번호는 🔐 보안 금고**(관리자 계정정보 카드)에 저장하세요.
깃 저장소나 일반 파일에 평문으로 두지 마세요.
