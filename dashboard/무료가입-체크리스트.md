## 1. 필수 — 수익/자동화 코어

### ✅ 쿠팡파트너스 — https://partners.coupang.com
- 가입 후 **채널(인스타/블로그) 등록 → 승인** 필요. 승인 전엔 링크 생성 제한.
- 받을 것: 파트너스 **딥링크/API 액세스 키**(설정 > 개발자).
- ⚠️ 대가성 문구 표기 의무 / 정품 링크만.

### ✅ n8n — https://n8n.io  (무료: 셀프호스팅)
- 무료로 쓰려면 **셀프호스팅**(`npx n8n` 또는 Docker). 클라우드는 유료/체험.
- 빠른 시작: 도커 한 줄 → `docker run -it --rm -p 5678:5678 n8nio/n8n`
- 받을 것: 워크플로 캔버스 + 각 서비스 API 키를 Credentials에 등록.

---

## 2. 크롤링 (둘 중 하나면 충분)

### ✅ Apify — https://console.apify.com/sign-up  (무료: 월 $5 크레딧, 카드 X)
- 기성 Actor(쿠팡/타오바오/1688 스크래퍼)로 바로 수집.
- 받을 것: **API 토큰**(Settings > Integrations).

### ✅ Firecrawl — https://www.firecrawl.dev  (무료: 영구 무료 플랜, 카드 X)
- URL→정제 JSON/마크다운. LLM·MCP 친화. 무료 1,000 크레딧/월 + MCP 서버.
- 받을 것: **API 키**(Dashboard).

### ✅ Playwright MCP — https://github.com/microsoft/playwright-mcp  (오픈소스, 가입 불필요)
- 클로드/에이전트에 붙여 브라우저 직접 조작. 설치만 하면 됨.

## 🔑 가입 후 할 일 (API 키 모으기)

자동화하려면 아래 키들을 **n8n Credentials**(또는 `.env`)에 모아두세요. 키는 절대 깃에 커밋 금지.

```
COUPANG_PARTNERS_ACCESS_KEY=
COUPANG_PARTNERS_SECRET_KEY=
APIFY_TOKEN=
FIRECRAWL_API_KEY=
FAL_KEY=
REPLICATE_API_TOKEN=
GEMINI_API_KEY=        # Google AI Studio
```

> 팁: 처음엔 **쿠팡파트너스 + n8n + Firecrawl(무료) + Canva/Gamma + Arting(무가입 영상)** 조합이
> 카드 없이 가장 빨리 시작하는 무료 스택입니다.
