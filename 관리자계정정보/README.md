# 🔐 관리자 계정정보

## 중요 — 먼저 읽으세요

- **이 폴더(깃 저장소)에는 실제 아이디·비밀번호를 절대 저장하지 마세요.** 깃에 올라간 비밀은
  되돌려도 기록에 남아 유출 위험이 큽니다.
- 실제 자격증명은 대시보드의 **🔐 보안 금고**(이중보안)에 입력하세요. 금고 데이터는
  **이 기기 브라우저에서 AES 암호화**되어 저장되고, 깃/서버에 올라가지 않습니다.
- **AI 어시스턴트(저)는 당신의 어떤 아이디·비밀번호도 알지 못합니다.** 따라서 대신 채워 넣을 수
  없고, 지어내지도 않습니다. 본인이 직접 금고에 입력하셔야 합니다.

## 이중보안이란

보안 금고는 두 가지가 **모두** 있어야 열립니다.
1. 마스터 비밀번호 (something you know)
2. 2차 PIN (추가 비밀)

두 값으로 PBKDF2(25만 회) → AES‑GCM 256 키를 만들어 항목을 암호화합니다.
⚠️ 둘 중 하나라도 잊으면 **복구 불가**합니다(평문이 어디에도 없기 때문).

## 사용법

1. 대시보드에서 `🔐 관리자 계정정보` 카드 → **🔐 보안 금고 열기**.
2. 최초 1회: 마스터 비밀번호 + PIN 설정.
3. `＋ 계정 추가`로 서비스/아이디/비밀번호/메모 입력.
4. 👁 보기, ⧉ 복사, ✎ 수정, 🗑 삭제.
5. 닫거나 `🔒 잠그기`를 누르면 메모리에서 즉시 잠깁니다.

## 더 안전하게 (권장)

은행·결제·핵심 업무 계정 등 **고가치 비밀**은 이 간이 금고 대신
1Password / Bitwarden 같은 전문 비밀번호 매니저 + OS 키체인 사용을 권장합니다.
이 금고는 "한 기기에서 메모용 자격증명을 암호화 보관"하는 용도에 적합합니다.

## 백업 주의

금고는 이 브라우저 저장소에만 있습니다. 브라우저 데이터를 지우면 사라집니다.
중요한 항목은 별도 안전한 매니저에도 보관하세요.
