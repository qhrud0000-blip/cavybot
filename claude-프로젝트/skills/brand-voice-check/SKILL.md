# brand-voice-check — 브랜드 보이스 검수

## 언제 쓰나
초안을 발행하기 전에 톤과 품질을 한 번 점검할 때. (다른 도구로 만든 글도 OK)

## 검수 기준 (마스터 프로필 기반)
1. **톤:** 친근한 존댓말, 옆자리 친구 느낌인가?
2. **난이도:** 비전공자가 읽고 바로 이해하나? 전문 용어에 풀이가 있나?
3. **금지어:** 충격/경악/100% 보장/무조건 등 자극·과장 표현 없나?
4. **구조:** 결론 먼저인가? 첫 문장이 후킹인가?
5. **구체성:** 막연한 표현 대신 숫자·예시가 있나?
6. **CTA:** 명확한 행동 유도 1개가 있나?
7. **이모지:** 과하지 않나(1~3개)?

## 출력 형식

```
✅ 브랜드 보이스 검수 결과

종합 점수: △/10
한 줄 평:

[항목별 체크]
- 톤: ⭕/⚠️/❌  — 코멘트
- 난이도: ...
- 금지어: ...  (발견 시 해당 표현 인용)
- 구조: ...
- 구체성: ...
- CTA: ...
- 이모지: ...

[수정 제안]
원문: "..."  →  수정: "..."
(중요한 것만 3~5개)

[바로 쓸 수정본 전체]
(검수 통과 버전 전문)
```

## 원칙
- 칭찬보다 **실질 개선**에 집중. 무엇을 왜 바꿨는지 한 줄로.
- 톤은 유지하되 정보 정확성도 함께 점검 (지어낸 통계 있으면 [확인 필요]).
