# 브랜드 보이스 검토기 (brand-voice-check)

## 목적
작성한 글이 @ai_ang2 브랜드 톤에 맞는지 검토하고 고쳐 쓴다.

## 브랜드 톤 기준
- 친근하고 쉬움 / 짧은 문장 / 결론 먼저
- 전문 용어는 일상어로 풀이
- 동료가 알려주는 느낌(가르치는 말투 금지)
- 과장·낚시 없이도 첫 줄은 궁금증 유발

## 검토 절차
1. 입력된 글을 톤 기준 5개 항목으로 0~5점 채점
2. 항목별로 문제 문장을 인용하고 이유 설명
3. 같은 의미를 브랜드 톤으로 다시 쓴 수정본 제시
4. "이 부분은 잘 맞음"도 1~2개 짚어 강화

## 출력 형식
- 점수표 → 문제점/수정 제안 → 최종 수정본
