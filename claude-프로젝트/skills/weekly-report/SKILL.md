# weekly-report — 주간 성과 리포트

## 언제 쓰나
한 주를 마무리하며 성과를 정리하고 다음 주 전략을 세울 때.

## 입력 (붙여넣기, 일부 없으면 [확인 필요])
- 발행 콘텐츠 목록 (제목/포맷/날짜)
- 콘텐츠별 지표 (조회/저장/공유/팔로우 증감/도달 등 가능한 것)
- 이번 주 목표(있었다면)

## 분석 규칙
1. 숫자는 **있는 것만** 사용. 없는 값은 지어내지 말고 [확인 필요].
2. "왜 잘됐나/안 됐나"를 후킹·주제·포맷 관점에서 추론.
3. 다음 주에 **바로 실행할 액션 3개**로 끝낸다.
4. 길게 쓰지 말고 표 + 불릿 위주.

## 출력 형식

```
📊 주간 리포트 — [기간]

[1] 한눈 요약
- 발행: N개 | 팔로우 증감: ±N | 베스트: "제목"
- 한 줄 총평:

[2] 콘텐츠별 성과 (표)
| 콘텐츠 | 포맷 | 저장 | 공유 | 도달 | 메모 |
|--------|------|------|------|------|------|

[3] 잘된 것 / 아쉬운 것
- 👍 (이유)
- 👎 (이유)

[4] 인사이트
- (반복되는 패턴 1~2개)

[5] 다음 주 액션 3개
1)
2)
3)
```

## 마무리
- 다음 주 콘텐츠 주제 후보 3개를 함께 제안.
- "이 주제로 대본 만들까요?" 한 줄 제안.
