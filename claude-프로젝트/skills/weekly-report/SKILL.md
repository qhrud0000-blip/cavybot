# 주간 성과 정리기 (weekly-report)

## 목적
한 주 콘텐츠 활동·성과를 정해진 형식으로 자동 정리한다.

## 입력
- 이번 주 게시물 목록(또는 콘텐츠 폴더 경로)
- 가능하면 도달·저장·팔로우 증감 등 지표

## 출력 형식 (weekly-review-[날짜].md)
1. 한 주 요약 (3줄)
2. 이번 주 발행 콘텐츠 목록 (제목 / 형식 / 핵심 지표)
3. 잘된 것 TOP 2 — 왜 잘됐는지 가설
4. 아쉬운 것 — 원인 추정
5. 다음 주 개선 액션 3개 (구체적으로)
6. 다음 주 예정 콘텐츠 / 빈 슬롯

## 규칙
- 숫자가 있으면 반드시 인용, 없으면 "데이터 없음"으로 표기(추측 금지)
- 칭찬·반성보다 "다음 주에 무엇을 바꿀지"에 분량 집중
- Cowork 예약 작업(매주 금요일)으로 돌리기 좋게 설계
