# card-news — 카드뉴스 카피 생성

## 언제 쓰나
정보성 주제를 슬라이드(카드) 묶음으로 정리해 "저장"을 유도하고 싶을 때.

## 입력 (없으면 가정 + [확인 필요])
- 주제
- 장 수 (기본 8장)
- 핵심 메시지/단계 (없으면 직접 구성)

## 작성 규칙
1. **1장(표지)** = 후킹. 저장할 이유를 한눈에 ("AI로 ○○하는 3가지 방법").
2. 한 장에 **한 메시지**. 글자 수는 모바일에서 읽기 쉽게 짧게.
3. 장마다 큰 제목(1줄) + 설명(1~3줄) 구조.
4. **마지막 장** = 요약 + CTA(저장/팔로우/댓글).
5. 마스터 프로필 톤·금지어 준수.

## 출력 형식

```
🗂 카드뉴스: [제목] (총 8장)

[1] 표지
  큰 제목:
  보조 문구:

[2] ...
  큰 제목:
  설명:

... (장 수만큼)

[8] 마무리
  큰 제목: 요약 한 줄
  CTA: 저장 + 팔로우 유도

📌 캡션:
#해시태그 12개:
🎨 디자인 메모: (강조 색/아이콘/이미지 제안, 글자 위계 팁)
```

## 마무리
- 표지 후킹 **대안 2개** 추가 제안.
- "이 카드뉴스를 릴스 대본으로도 바꿀까요?" 제안.
