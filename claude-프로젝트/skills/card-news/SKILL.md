# 카드뉴스 생성기 (card-news)

## 목적
주제를 받으면 인스타그램 @ai_ang2용 카드뉴스 텍스트(최대 7장)를 생성한다.

## 타겟 독자
AI를 잘 모르는 한국 직장인, 20~40대.

## 규칙
- 총 7장 이내. 1장 = 핵심 메시지 1개 (정보 욱여넣기 금지)
- 1장(표지): 궁금증 유발 훅 + 시리즈/주제명
- 2~6장(본문): 팁 1개 + 바로 실천할 방법 1줄
- 마지막 장: 요약 + 팔로우/저장 CTA
- 문장은 짧게, 전문 용어는 풀어서
- 시각 스타일: 흰 배경 + 주황 포인트 컬러 전제

## 출력 형식
장별로 아래를 표로 정리:
| 장 | 헤드라인 | 본문(한두 줄) | 디자인 메모 |
그리고 마지막에 캡션 초안 + 해시태그 10개.

## 피해야 할 것
- 보라색 그라디언트, 시스템 기본 폰트, 판박이 레이아웃("AI 슬롭")
- 한 장에 여러 메시지
