# reel-script — 릴스 대본 생성

## 언제 쓰나
주제/키워드 하나로 15~40초짜리 릴스 대본이 필요할 때.

## 입력 (없으면 합리적으로 가정하고 [확인 필요] 표시)
- 주제 (예: "ChatGPT로 회의록 정리")
- 길이 (기본 30초)
- 목표 (저장 / 팔로우 / 댓글 중 기본=저장)

## 작성 규칙
1. **첫 1초 후킹**이 생명. 스크롤을 멈추게 하는 질문/반전/숫자로 시작.
2. 비전공자 눈높이. 전문 용어는 즉시 한 줄 풀이.
3. 마스터 프로필의 톤·금지어 준수 (자극적 낚시 금지).
4. 화면 자막과 나레이션을 분리해서 제공.
5. 마지막은 CTA 1개로 명확하게.

## 출력 형식 (이 구조를 그대로 사용)

```
🎬 릴스 대본: [제목]
⏱ 길이: 약 30초 | 🎯 목표: 저장

[0~3초] 후킹
- 자막: (화면에 크게 뜰 문구)
- 멘트: (말로 할 내용)

[3~8초] 문제/공감
- 자막:
- 멘트:

[8~25초] 해법 시연 (단계)
1) ...
2) ...
3) ...
- (각 단계 자막 + 멘트)

[25~30초] CTA
- 자막:
- 멘트:

📌 캡션(첫 줄 후킹 포함):
#해시태그 12개:
🎥 촬영 메모: (화면 녹화/직접촬영, B롤, 자막 위치 팁)
```

## 마무리
- 같은 주제로 **다른 훅 2개**를 추가 제안한다 ("훅 A안/B안").
- 끝에 "이 대본으로 카드뉴스 변환할까요?" 한 줄 제안.
