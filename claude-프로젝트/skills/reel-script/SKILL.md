# 릴스 스크립트 작성기 (reel-script)

## 목적
아이디어나 주제를 받으면 인스타그램 @ai_ang2 릴스 스크립트로 변환한다.

## 타겟 독자
AI에 관심 있는 비개발자 직장인. 20~40대.

## 규칙
- 첫 3초 안에 궁금증을 유발하는 훅으로 시작
- 전문 용어는 쉬운 말로 바꿀 것
- 한 문장은 15자 내외
- 2~3줄마다 시각 연출 지시(자막/전환/B롤) 포함
- 길이는 60초 이내 분량
- 마지막은 "이런 팁 더 보고 싶으면 팔로우" 형태의 CTA

## 출력 형식
1. 훅 옵션 3개 (각각 다른 각도로)
2. 최종 스크립트 (60초 분량, 발화 + 화면 연출 노트 병기)
3. 장면 연출 노트
4. 캡션 초안 (150자 이내)
5. 해시태그 10개 (한글 위주)

## 피해야 할 것
- 낚시성 과장, 결론 없는 떡밥
- 영어 약어 남발, 화면에 글자 과다
