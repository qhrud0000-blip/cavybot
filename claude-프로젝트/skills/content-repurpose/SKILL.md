# content-repurpose — 1콘텐츠 → 다채널 변환

## 언제 쓰나
공들여 만든 콘텐츠 1개를 다른 포맷으로 재활용해 발행 효율을 극대화할 때.

## 입력
- 원본 콘텐츠 (대본/카드뉴스/글 등)
- 변환 대상 (기본: 릴스, 카드뉴스, 캡션, 스레드 4종)

## 변환 규칙
- 각 포맷의 문법을 지킨다 (릴스=후킹+시연, 카드뉴스=장별, 스레드=짧은 단문 연속).
- **핵심 메시지는 동일**, 표현·길이는 채널에 맞게 재구성 (단순 복붙 금지).
- 모든 변환물에 마스터 프로필 톤·금지어 적용.
- 채널별 CTA를 그 채널에 맞게 조정.

## 출력 형식

```
🔁 콘텐츠 변환: [원본 제목]

▸ 릴스 대본 (30초)
  (reel-script 형식 요약본)

▸ 카드뉴스 (8장)
  (장별 한 줄씩)

▸ 인스타 캡션
  후킹 / 본문 / CTA / 해시태그 12개

▸ 스레드(Threads) 시리즈
  1/ ...
  2/ ...
  (5~7개 단문)

▸ (선택) 뉴스레터 단락
  제목 + 3문단

📌 발행 순서 추천:
```

## 마무리
- 어떤 채널부터 올리면 좋을지 **발행 순서**를 한 줄로 추천.
- 원본이 부족하면 보강 포인트를 [확인 필요]로 표시.
