# 콘텐츠 재가공기 (content-repurpose)

## 목적
하나의 콘텐츠(릴스/카드뉴스/글)를 여러 플랫폼·형식용으로 변환한다.

## 입력
원본 콘텐츠 1개 + 어떤 형식으로 바꿀지(없으면 아래 전체 생성).

## 변환 대상
- 인스타 릴스 스크립트 (60초)
- 카드뉴스 텍스트 (7장 이내)
- 인스타 캡션 (150자) + 해시태그
- 스레드/트위터형 짧은 글 묶음
- 블로그/뉴스레터용 확장 글
- 강의·세일즈에 쓸 한 줄 후킹 카피

## 규칙
- 플랫폼별 길이·톤 관습에 맞게 재구성 (단순 복붙 금지)
- 핵심 메시지는 유지하되 각 형식의 강점 살리기
- @ai_ang2 톤(친근·쉬움·짧은 문장) 유지
- 각 산출물 끝에 형식에 맞는 CTA

## 출력 형식
- 형식별 섹션으로 구분해 한 번에 제시
