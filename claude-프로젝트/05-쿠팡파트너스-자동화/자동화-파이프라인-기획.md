# 쿠팡파트너스 자동 수익 파이프라인 — 기획서

> 목표: **클릭률 상위 상품 발굴 → (소싱/레퍼런스) 크롤링 → 상세페이지 자동 제작 → 쿠팡파트너스 링크 연동·등록 → 수익화**를
> 사람 개입 최소로 돌리는 반자동 파이프라인.

---

## ⚠️ 먼저 읽을 컴플라이언스 (중요)

이 파이프라인은 합법적인 범위 안에서만 돌려야 안전합니다. 아래는 반드시 지키세요.

1. **이미지·문구 저작권**: 중국 쇼핑몰(타오바오/1688/알리 등)의 상품 사진·상세컷·문구를 **그대로 복제 게시하면 저작권/초상권 문제**가 생길 수 있습니다.
   - 권장: 크롤링 데이터는 **레퍼런스(사양·치수·키워드)** 로만 쓰고, 이미지는 **직접 촬영하거나 AI로 재생성**, 문구는 **새로 작성**.
2. **쿠팡파트너스 약관**: 대가성 문구 표기 의무, 금지 카테고리, 가격/딥링크 규정 준수. 쿠팡에 **없는 상품**의 가짜 링크 생성 금지 — 쿠팡에 실제 존재하는 상품에만 파트너스 링크를 단다.
3. **대가성 문구 필수**: 모든 게시물에 "이 포스팅은 쿠팡파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
4. **사이트 robots/ToS 존중**: 과도한 크롤링·우회 금지. 공개 API/허용 범위 우선.
5. **허위·과장 금지**: 써보지 않은 효능 단정 X.

> 요약: "중국 사이트 = **트렌드/사양 리서치 소스**, 실제 판매·링크 = **쿠팡 정품**, 비주얼·카피 = **내가 새로 생성**." 이 구도가 가장 안전하고 지속 가능합니다.

## 전체 흐름 (6단계)

```
[1] 발굴   클릭률/판매 상위 상품 자동 수집
   ↓
[2] 리서치 중국 사이트에서 사양·키워드·트렌드 크롤링 (레퍼런스용)
   ↓
[3] 매칭   동일/유사 상품을 쿠팡에서 검색 → 파트너스 링크 발급
   ↓
[4] 제작   상세페이지(텍스트+이미지+영상) 자동 생성
   ↓
[5] 등록   블로그/상세페이지 자동 게시 + 링크 삽입 + 대가성 문구
   ↓
[6] 추적   클릭·전환 수집 → 주간 리포트 → 잘되는 것 강화
```

## 단계별 도구 (무료·MCP 우선)

| 단계 | 할 일 | 추천 도구 (대시보드 'MCP 추천'에 수록) |
|------|-------|------|
| 1. 발굴 | 인기/클릭 상위 상품 수집 | 쿠팡 베스트 페이지 + **Apify**, **Firecrawl** |
| 2. 크롤링 | 사양·키워드 레퍼런스 | **Apify**, **Playwright MCP**, **ScrapeGraphAI** |
| 3. 매칭/링크 | 쿠팡 검색→파트너스 링크 | 쿠팡파트너스(딥링크), **n8n** 오케스트레이션 |
| 4. 상세페이지 | 카피+이미지+영상 | **Gamma**(상세페이지), **Canva/VistaCreate**(배너·명함), **Leonardo/Ideogram**(이미지), **Replicate/fal.ai/Remotion**(영상) |
| 5. 등록 | 자동 게시 | **n8n/Make**(블로그 API 연동), 워드프레스/티스토리 |
| 6. 추적 | 성과 분석 | 쿠팡파트너스 리포트 + `skills/weekly-report` |

> n8n 하나를 '오케스트레이터'로 두고 각 단계 API를 노드로 연결하는 구조를 권장합니다. (셀프호스팅 무료)

## 자동화 아키텍처 (권장)

```
                 ┌─────────────── n8n (오케스트레이터, 무료 셀프호스팅) ───────────────┐
                 │                                                                      │
 [크론 트리거] → │  Apify/Firecrawl ─→ (사양·키워드) ─→ Gemini/Claude 가공 ─→            │
                 │  쿠팡 검색·딥링크 ─→ Gamma 상세페이지 ─→ Canva 배너 ─→ Replicate 영상 │
                 │       └─→ 블로그/사이트 자동 게시(+대가성 문구) ─→ 성과 수집          │
                 └──────────────────────────────────────────────────────────────────────┘
```

- **MCP 활용 포인트**: Claude/에이전트에 Playwright·Firecrawl·Apify MCP를 붙이면 "수집→가공→초안"을 대화형으로 자동화.
- **사람 개입(권장 체크포인트)**: ③ 쿠팡 상품 매칭 확인, ⑤ 게시 전 대가성·과장 최종 검수(`brand-voice-check`).
