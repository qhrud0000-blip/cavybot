# claude-프로젝트

Claude의 강점(긴 맥락 유지, 톤 일관성, 구조화·검수, 지침 준수)에 맞춰 설계한 4개 프로젝트와 스킬 모음입니다.

## 세팅 방법

1. Claude에서 **새 Project** 생성 (프로젝트 이름은 아래 번호+이름 그대로 권장)
2. 해당 폴더의 `프로젝트-지침.md` 내용을 **Project Instructions(프로젝트 지침)** 에 붙여넣기
3. 그 아래에 [`../공통/마스터-프로필.md`](../공통/마스터-프로필.md) 내용을 이어 붙이기
4. 자주 쓰는 작업은 `skills/`의 해당 SKILL.md를 채팅 첫 메시지로 붙여 호출
