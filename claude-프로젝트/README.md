# Claude 프로젝트 세팅

Claude 앱의 **Projects** 기능으로 만드는 4개의 독립 작업 공간 + Claude Code/Cowork용 **Skills**입니다.
프로젝트는 각각 별도의 지침·파일·대화 기록을 가지므로, 주제를 섞지 않고 전문적으로 처리됩니다.

## 프로젝트 4종

| 폴더 | 프로젝트 이름 | 용도 |
|------|---------------|------|
| 01-콘텐츠-작업실 | 콘텐츠 작업실 | 인스타 카드뉴스·릴스 제작 전용 |
| 02-업무-자동화 | 업무 자동화 | 반복 업무·스크립트·데이터 처리 |
| 03-사이드-프로젝트 | 사이드 프로젝트 | 강의·프리랜서 수익화 기획 |
| 04-커리어-관리 | 커리어 관리 | 이직·자기소개·면접 준비 |

## 만드는 법
1. Claude 앱 좌측 **Projects → Create project**
2. 위 표의 이름으로 프로젝트 생성
3. 각 폴더의 `프로젝트-지침.md` 본문(코드블록 안)을 복사해 **Project instructions**에 붙여넣기
4. 폴더 설명에 적힌 **업로드 추천 파일**을 프로젝트 Knowledge에 올리기

## Skills
`skills/` 의 각 `SKILL.md`는 Claude Code/Cowork에서 `.claude/skills/<이름>/SKILL.md` 경로에 두면
관련 상황에서 자동 발동됩니다. (예: 릴스 대본 요청 시 `reel-script` 자동 적용)
