# chatgpt-프로젝트

ChatGPT의 강점(**이미지 생성, 빠른 초안, 가벼운 브레인스토밍, 웹 탐색**)에 맞춰 최적화한 4개 프로젝트 지침입니다.
Claude 프로젝트와 같은 4개 주제지만, 역할 분담이 다릅니다.

## Claude와의 역할 분담

| | Claude | ChatGPT |
|--|--------|---------|
| 콘텐츠 | 대본·검수·구조화 | **아이디어 발산·빠른 초안** |
| 비주얼 | — | **썸네일·이미지 생성** |
| 업무 | 정교한 템플릿 | **빠른 답변·간단 정리** |
| 사이드 | 커리큘럼 설계 | 시장 빠른 조사·표지 시안 |
| 커리어 | 제안서·문체 다듬기 | 초안·아이디어 |

> 원칙: **"만들기(초안·이미지)는 ChatGPT, 다듬기는 Claude."**

## 세팅 방법

1. ChatGPT에서 **프로젝트(Projects)** 생성
2. 해당 폴더 `프로젝트-지침.md`를 프로젝트 지침에 붙여넣기
3. 그 아래 [`../공통/마스터-프로필.md`](../공통/마스터-프로필.md) 이어 붙이기
4. 이미지가 필요한 작업은 이 프로젝트에서, 최종 대본·검수는 Claude로 넘긴다
