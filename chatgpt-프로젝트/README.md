# ChatGPT 프로젝트 세팅

ChatGPT의 **Projects** 기능으로 만드는 4개의 독립 작업 공간입니다.
Claude 프로젝트와 주제는 동일하지만, ChatGPT의 강점(빠른 초안, 이미지 생성, 프로젝트 메모리)에 맞춰 문구를 최적화했습니다.

## 프로젝트 4종

| 폴더 | 프로젝트 이름 | 용도 |
|------|---------------|------|
| 01-콘텐츠-작업실 | 콘텐츠 작업실 | 인스타 카드뉴스·릴스 초안·이미지 |
| 02-업무-자동화 | 업무 자동화 | 반복 업무·데이터·간단 스크립트 |
| 03-사이드-프로젝트 | 사이드 프로젝트 | 강의·프리랜서 수익화 기획 |
| 04-커리어-관리 | 커리어 관리 | 이직·자기소개·면접 준비 |

## 만드는 법
1. ChatGPT 좌측 사이드바 **Projects(프로젝트) → New project**
2. 위 표의 이름으로 생성
3. 각 폴더 `프로젝트-지침.md`의 코드블록 본문을 복사 → 프로젝트 **Instructions(지침)** 에 붙여넣기
4. **업로드 추천 파일**을 프로젝트 파일로 올리기

- **긴 전략·대본·코드·자동화 실행**은 Claude 쪽이 유리
