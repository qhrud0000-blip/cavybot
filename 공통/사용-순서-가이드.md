# 사용 순서 가이드 — 도구/모델 선택 + 주말 세팅 플랜

이 문서는 **"지금 이 작업, Claude로 할까 ChatGPT로 할까? 어떤 순서로?"**를 1초 안에 정하기 위한 치트시트입니다.

---

## 1. 한 줄 원칙

> **만들기(초안·이미지·아이디어)는 ChatGPT, 다듬기(대본·검수·리포트·구조화)는 Claude.**

---

## 2. 작업별 도구 선택표

| 작업 | 1순위 | 2순위 | 메모 |
|------|-------|-------|------|
| 콘텐츠 아이디어 30개 뽑기 | ChatGPT | Claude | 양으로 승부, 빠르게 |
| 릴스 대본 작성 | **Claude** | ChatGPT | 톤 일관성·구조 → reel-script 스킬 |
| 카드뉴스 카피 | **Claude** | ChatGPT | 장별 분량 통제 → card-news 스킬 |
| 썸네일·이미지 시안 | **ChatGPT** | — | 이미지 생성 내장 |
| 캡션·해시태그 | Claude | ChatGPT | 둘 다 OK, 톤은 Claude |
| 브랜드 보이스 검수 | **Claude** | — | brand-voice-check 스킬 |
| 1콘텐츠 → 다채널 변환 | **Claude** | ChatGPT | content-repurpose 스킬 |
| 주간 성과 리포트 | **Claude** | — | weekly-report 스킬 |
| DM/댓글 답변 템플릿 | Claude | ChatGPT | 02-업무자동화 |
| 빠른 사실 확인·요약 | ChatGPT | Claude | 웹검색 빠른 쪽 |
| 전자책/강의 커리큘럼 | **Claude** | ChatGPT | 긴 구조화 → 03-사이드 |

---

## 3. Claude 모델 선택

- **기본:** 가장 똑똑한 최신 모델(Opus)을 쓴다. 대본·검수·리포트처럼 품질이 중요한 작업.
- **빠른 반복·가벼운 작업:** 빠른 모델(Haiku/Sonnet)로 충분 — 아이디어 다듬기, 짧은 변형.
- **팁:** 결과물의 "퀄리티가 곧 브랜드"인 작업은 아끼지 말고 최고 모델로.

> 참고: 특정 모델이 일시적으로 사용 불가일 때(예: 점검)는 대체 모델로 진행하고, 톤 검수만 최고 모델로 다시 돌리면 손실이 적습니다.

---

## 4. 표준 작업 흐름 (콘텐츠 1개 만들 때)

```
[1] 기획   ChatGPT로 아이디어 20~30개 → 1개 선정
   ↓
[2] 대본   Claude 01-콘텐츠작업실 + reel-script 스킬
   ↓
[3] 비주얼 ChatGPT로 썸네일/이미지 시안 생성
   ↓
[4] 검수   Claude brand-voice-check 스킬로 톤 점검
   ↓
[5] 변환   Claude content-repurpose로 카드뉴스·스레드·캡션 파생
   ↓
[6] 발행   직접 업로드 (또는 예약)
   ↓
[7] 분석   주말에 Claude weekly-report로 성과 정리
```

---

## 5. 주말 세팅 플랜 (토/일 2시간으로 한 주 준비)

### 토요일 — 셋업 & 채우기 (약 1시간)
1. **(최초 1회)** Claude·ChatGPT에 4개 프로젝트 생성, 각 `프로젝트-지침.md` + `마스터-프로필.md` 붙여넣기.
2. ChatGPT에서 **다음 주 콘텐츠 아이디어 20개** 생성 → 5개 선정.
3. 선정한 5개를 Claude 01-콘텐츠작업실에 넣고 **릴스 대본 5개** 초안 생성.

### 일요일 — 다듬기 & 예약 (약 1시간)
4. 대본 5개를 brand-voice-check로 한 번에 검수.
5. content-repurpose로 각 대본을 카드뉴스/캡션으로 파생.
6. ChatGPT로 썸네일 5장 생성.
7. 한 주치 발행 일정 잡고(예약 가능하면 예약), 지난 주 weekly-report 정리.

> **결과:** 평일에는 "발행 + 소통"만. 제작은 주말에 끝.

---

## 6. 막힐 때 체크리스트

- 결과물이 밋밋하다 → 마스터 프로필의 "말투 예시"를 다시 첨부했는지 확인
- 톤이 자꾸 광고 같다 → brand-voice-check로 돌리고 "금지어" 목록 강조
- 매번 설명이 길다 → "완성본만, 설명 최소화"라고 한 줄 추가
- 아이디어가 안 나온다 → ChatGPT에 "최근 저장/공유 많은 AI 꿀팁 주제 트렌드" 요청
