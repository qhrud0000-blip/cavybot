# 사용 순서 가이드 — 무엇을, 언제 쓰나

## 1. 작업별 도구 선택

| 하고 싶은 것 | 쓸 것 |
|--------------|-------|
| 상세페이지·카피 기획/작성 | 상품상세페이지 자동화 / 마케팅 프로젝트 |
| 쇼핑몰 운영 자동화·CS·상품등록 | 쇼핑몰 자동화 프로젝트 (+ Cowork 예약) |
| 후기·리뷰 정리/작성 | 사용후기 프로젝트 |
| 업종별(화장품/인테리어) 전문 카피 | 해당 카테고리 프로젝트 |
| 캠페인·퍼널·광고 전략 | 마케팅 프로젝트 (+ Extended Thinking) |
| 비주얼·브랜드·시안 | 디자인 프로젝트 (+ Claude Design / Figma / Canva) |
| 콘텐츠 제작·발행 | 인스타/유튜브/블로그 프로젝트 |
| 강의 기획·교안·실습 | 바이브코딩강의 프로젝트 |
| 시장·경쟁 조사 | 아무 프로젝트 + Deep Research ON |
| 반복 업무 자동화 | Cowork → /schedule |
| 법률 문서 정리·초안 | 가사 / 가처분 프로젝트 (변호사 검토 필수) |

## 2. 모델 선택
- 일상 초안·카피 90% → **Sonnet**
- 전략 수립·긴 문서·법률 문서 교차분석 → **Opus + Extended Thinking**
- 단순 치환·요약 → **Haiku**

## 3. 연동(MCP) 활용 — 필요할 때만 ON (토큰 절약)
- **Gmail**: 클라이언트 메일 분류·답장 초안
- **Google Drive**: 작업 파일·클라이언트 폴더 읽기
- **Google Calendar**: 납기·미팅·기일 일정
- **Notion**: 프로젝트/사건 관리 DB
- **Figma / Canva**: 디자인 시안

## 4. 안전 규칙
- 안전하게 시작: 요약·초안·리서치·파일 분류(이동만)
- 신중히: 메일 자동 발송, 파일 삭제, 결제, 클라이언트·법률 데이터 처리
- 외부 발송·게시물 업로드·삭제는 **사람이 최종 확인 후 실행**
