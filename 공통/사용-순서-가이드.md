## 3. 주말 이틀 세팅 플랜

### Day 1 — 기반 구축
1. **Chat 기본 설정** — 메모리 토글 ON, `공통/마스터-프로필.md` 등록, 프로젝트 4개 생성 후 각 지침 붙여넣기
2. **Cowork 설정** — Desktop 앱 설치, 플러그인 2~3개(Productivity/Marketing), 첫 예약 작업 `/schedule`
3. **Design 설정** — 브랜드 키트 생성(@ai_ang2 피드 캡처 업로드), 카드뉴스 커버 1장 테스트
4. **Code 설정(선택)** — `npm install -g @anthropic-ai/claude-code`, `/init` 후 CLAUDE.md 채우기, 스킬 폴더 복사

### Day 2 — 실전 적용
1. Deep Research / Extended Thinking로 실제 주제 1건씩 돌려보고 일반 채팅과 품질 비교
2. 매주 가장 귀찮은 수동 작업 1개를 Cowork 예약 작업으로 자동화
3. 전체 점검 — 메모리 확인, 프로필 보완, 스킬 테스트, Design 에셋 1개 실제 발행

## 4. 안전 규칙

- **먼저 시작해도 안전:** 요약·초안, 리서치, 아이디어 생성, 파일 정리(이동/분류만)
- **신중하게:** 이메일 자동 발송, 파일 삭제, 결제, 클라이언트 데이터 처리
- Claude Code `/permissions`로 접근 범위를 미리 제한. Cowork는 영구 삭제 전 반드시 승인 요청.
